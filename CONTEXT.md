# Skills autocomplete

This project helps people put discovered opencode skills into a TUI prompt and prepares its own versioned releases.

## Language

**Skill selection**:
Choosing a discovered skill to add its `/name ` reference to the prompt without submitting it.
_Avoid_: Skill execution

**Standalone slash**:
A `/` typed with whitespace or the prompt edge directly on each side. Typing a slash opens a skill list only when it is standalone.
_Avoid_: Trigger slash

**Release preparation**:
Recording the next product version and its matching changelog entry before publication.
_Avoid_: Publishing
